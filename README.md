# Taller de Recursividad
Este repositorio contiene la solución a un taller académico de estructuras de datos enfocado en la resolución de problemas mediante **recursividad** en Java

## Estudiante
David Santiago Pacheco Ortega
Ingenieria Informatica IV semestre

## Descripción del Taller
1. Cálculo de Factorial (`Ejercicio1`)
2. Inversión de un número entero (`Ejercicio2`)
3. Sumatoria armónica (`Ejercicio3`)
4. Suma de los dígitos de un número (`Ejercicio4`)
5. Sumatoria acumulativa hasta N (`Ejercicio5`)
6. Potencia de un número (`Ejercicio6`)
7. Máximo Común Divisor (MCD) por Algoritmo de Euclides (`Ejercicio7`)
8. Copia de una cadena de caracteres (`Ejercicio8`)
9. Cociente de división entera por restas sucesivas (`Ejercicio9`)
10. Multiplicación por sumas sucesivas (`Ejercicio10`)
11. Suma de elementos de un vector (`Ejercicio11`)
12. Suma de elementos de una matriz (`Ejercicio12`)
13. Generación e impresión de la serie de Fibonacci hasta un límite (`Ejercicio13`)
14. Función de Ackermann (`Ejercicio14`)

Además, cuenta con una clase central `Main.java` encargada de orquestar y ejecutar las pruebas de todos los ejercicios.
